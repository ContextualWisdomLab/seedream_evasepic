## 2023-11-20 - [CLI UX Enhancement] ANSI Color Codes for Bash Scripts
**Learning:** CLI 플러그인(특히 Bash 스크립트 기반)에서 시각적 피드백이 부족하면 사용자가 에러나 진행 상황을 파악하기 어렵다는 점을 배웠습니다. 에러 메시지는 빨간색, 성공은 초록색, 중요한 정보나 진행 상황은 청록색이나 노란색으로 시각적 구분을 주어 터미널 환경에서도 직관적인 UX를 제공하는 것이 중요합니다.
**Action:** `download-reference.sh`, `extract-frames.sh`, `transcribe.sh` 스크립트의 출력 메시지에 일관된 ANSI 색상 코드(RED, GREEN, YELLOW, CYAN, NC 등)를 추가하여 터미널 내 가독성과 정보 인지 속도를 개선합니다. 향후 새로운 스크립트 작성 시에도 기본으로 컬러 피드백을 적용할 것입니다.
## 2024-05-18 - [CLI UX Enhancement] Accessible Help Commands for Bash Scripts
**Learning:** In CLI tools, argument parsing and help flags (`-h` or `--help`) must be evaluated *before* any system dependency checks (like `ffmpeg`, `yt-dlp`). If dependency checks run first, users cannot even read the basic documentation to understand how to use the script or what dependencies they need to install. This is an accessibility issue for CLI environments.
**Action:** Always place help flag checks at the very top of script execution flow, immediately after variable assignment, so users can access usage instructions unconditionally.
