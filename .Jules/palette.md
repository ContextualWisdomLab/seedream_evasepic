## 2024-05-24 - CLI 스크립트 도움말 옵션 표준화
**학습 (Learning):** 터미널 기반 CLI 도구에서 사용자가 스크립트 실행 방법을 몰라 의존성 검사에서 막히는 경험은 매우 좋지 않은 UX입니다. 인자 파싱 이전에 의존성 검사를 수행하면 사용자는 도움말 옵션(`-h`, `--help`)조차 볼 수 없게 됩니다.
**조치 (Action):** 모든 쉘 스크립트에서 도움말 플래그 확인 로직(`-h`, `--help`)을 항상 가장 먼저 수행하고, 의존성 검사(`yt-dlp`, `ffmpeg` 등)는 그 이후에 수행하도록 스크립트 구조를 표준화해야 합니다.
