## 2024-10-24 - yt-dlp 옵션 인젝션 취약점 방지
**Vulnerability:** yt-dlp를 래핑하는 셸 스크립트에서 사용자의 동적 입력값(URL)을 안전하게 처리하지 않아 옵션 인젝션이 발생 가능함.
**Learning:** yt-dlp와 같은 외부 CLI 도구는 하이픈(-)으로 시작하는 문자열을 옵션으로 인식하므로, 악의적인 사용자가 `--exec` 등의 옵션을 주입할 경우 임의의 코드 실행(RCE) 등 심각한 결과를 초래할 수 있음.
**Prevention:** CLI 래퍼 스크립트에서 사용자 입력값을 전달할 때는 반드시 `--`를 사용하여 옵션 파싱을 명시적으로 종료한 후 변수(예: `-- "$URL"`)를 전달해야 함.
