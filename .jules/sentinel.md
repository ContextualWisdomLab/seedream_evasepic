## 2024-05-24 - awk string interpolation command injection vulnerability
**Vulnerability:** A command injection vulnerability existed in `extract-frames.sh` where user-provided input (`$NUM_FRAMES`) was directly interpolated into an `awk` script string: `awk "BEGIN { printf \"%.6f\", $NUM_FRAMES / $DURATION }"`. An attacker could pass a crafted string like `12 } BEGIN { system("id") } BEGIN { print 1` to execute arbitrary commands.
**Learning:** Directly interpolating shell variables into `awk` scripts using double quotes allows for command injection if the variable contains unexpected characters or `awk` script syntax.
**Prevention:** Always use the `-v` option in `awk` to pass shell variables safely (e.g., `awk -v num="$NUM_FRAMES" -v dur="$DURATION" 'BEGIN { printf "%.6f", num / dur }'`) and use single quotes for the `awk` script itself to prevent shell expansion and injection. Additionally, validate and sanitize all user inputs using strict regex (e.g., `echo "$VAR" | grep -Eq '^[1-9][0-9]*$'`) before using them in any operations.
