## 2026-07-05 - CLI 툴 도움말 접근성 개선 (Dependency Check 순서 조정)
**Learning:** CLI 스크립트에서 의존성 검사(dependency check)를 인자(argument) 검사보다 먼저 수행하면, 사용자가 `-h` 또는 `--help` 플래그로 사용법을 확인하려 할 때 의존성 패키지가 없으면 도움말조차 보지 못하고 차단되는(blocking) UX 안티 패턴이 발생함을 확인했습니다.
**Action:** 앞으로 모든 CLI 스크립트 작성 시에는 `-h`나 `--help` 같은 도움말 플래그를 가장 먼저 검사(loop 처리 등)하여 처리하고, 그 이후에 실제 명령 실행에 필요한 외부 의존성(예: ffmpeg 등)을 체크하도록 로직 순서를 강제하여 CLI 툴의 사용성을 개선해야 합니다.
