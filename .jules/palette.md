
## 2024-10-24 - CLI 스크립트 도움말 UX 개선
**Learning:** CLI 도구 사용 시 종속성 검사가 인수 구문 분석보다 먼저 실행되면, 필수 종속성이 설치되어 있지 않을 때 사용자가 도움말(-h, --help)조차 확인할 수 없어 UX가 크게 저하됨. 모든 인수를 확인하는 루프를 통해 도움말을 우선적으로 제공해야 함.
**Action:** -h 및 --help 확인 루프를 도입하여 도움말 요청 시 exit 0을 반환하도록 하고, 종속성 검사를 인자 파싱 이후로 이동함. 또한 호환성 문제가 있는 echo -e 대신 printf "%b\n"을 사용하도록 수정함.
