# Analysis Dimensions — The 8-Dimension Rubric

Every reference video is analyzed across these 8 dimensions. For each, identify the **transferable pattern** (structural/aesthetic) — NOT the specific content (product/brand/person).

Only patterns go into `reference-style.md`. Content gets replaced by the user's product.

---

## 1. Structure & pacing

**Ask:**
- How many distinct beats/shots?
- What's the typical beat length? (sub-1s fast cuts vs 3-5s held shots)
- What's the narrative arc? (hook → demo → verdict / reveal → detail → CTA / setup → payoff)
- Does it build, stay flat, or peak-and-release?

**Transferable patterns:**
- Beat count per 15s
- Rhythm: fast (6+ cuts/15s) / medium (3-5) / slow (1-2)
- Arc shape: rising / flat / spike

**NOT transferable:** the specific content of each beat

---

## 2. Camera & framing

**Ask:**
- Primary POV: selfie / tripod / handheld / over-the-shoulder / drone?
- What's the signature movement? (dolly / pan / tracking / static / orbit)
- Shot rhythm across beats: (wide → medium → close) vs (all close) vs (alternating)
- Is framing consistent or intentionally varied?

**Transferable patterns:**
- POV class
- One or two signature movements
- Shot-rhythm grammar

**NOT transferable:** what's in each shot

---

## 3. Edit style

**Ask:**
- Cut type: jump cuts / dissolves / match cuts / L-cuts?
- Transition energy: hard snap / soft fade / motion match?
- Recurring visual motifs: (e.g., "every other beat is a close-up" / "every speech line has a framing change")
- Any VFX flourishes? (text pop, zoom punch, speed ramp)

**Transferable patterns:**
- Cut vocabulary
- Motif rules
- Transition language

---

## 4. Dialogue & script

**Ask:**
- Hook format: question / declarative / reaction / mid-action?
- Speech pattern: casual with filler / scripted / voice-over / text-on-screen?
- Dialogue density: words per second (count transcript words / duration)
- Silent-vs-spoken ratio
- CTA style: direct ("link in bio") / soft ("you'll see") / absent

**Transferable patterns:**
- Hook grammar ("Have you ever...?" / "I have to tell you..." / etc.)
- Filler word habits ("okay so", "honestly", "진짜")
- Line length pattern (short punchy vs long flowing)

**NOT transferable:** specific words/claims

---

## 5. Tone & energy

**Ask:**
- 3-4 emotion words that describe the speaker
- Energy arc: builds / flat / peaks then settles?
- Relationship to viewer: talking to a friend / expert to student / narrator to audience?
- Pacing cues the model uses (pauses, breath, filler)

**Transferable patterns:**
- Emotion vocabulary
- Energy shape
- Viewer-relationship posture

---

## 6. Lighting & technical quality

**Ask:**
- Light source: natural window / ring light / practicals / mixed?
- Color grade: warm / cool / desaturated / high-contrast?
- Intentional "flaws": phone grain, motion blur, auto-WB shifts, overexposure?
- Overall technical class: phone-raw / edited-phone / DSLR-polished / cinema?

**Transferable patterns:**
- Light source class
- Grade direction
- Flaw vocabulary

---

## 7. Product / subject handling

**Ask:**
- How does the hero subject (product) enter? (already there / gradual / sudden reveal)
- Featured details: texture / label / before-after / ingredient?
- Is it held / worn / applied / displayed?
- How does the subject exit the frame (or does it)?

**Transferable patterns:**
- Reveal grammar
- Interaction style
- Exit pattern

---

## 8. Distinctiveness — the 2-3 that define this style

**Ask:** After cataloging all 7 dimensions above, what 2-3 things make THIS style recognizable?

Examples:
- "Every close-up is backlit with a single warm practical" (Preset 3 / Editorial)
- "Dialogue always ends mid-thought with a small laugh" (Preset 4 / Bright Clean)
- "Extreme macro shots outnumber wide shots 3-to-1" (Preset 5 / Ritual)

These 2-3 traits become the **core** of the reusable template. Everything else is secondary.

---

## Outputs per dimension

For each dimension, produce:
- **2-4 bullet observations** (what you see in the reference)
- **1 transferable pattern rule** (how to apply this to any new content)
- **1 thing to avoid** (the pattern's anti-example)

---

## Keeping content out

**The most common mistake:** describing what's IN the reference video instead of its STYLE.

| Wrong (content) | Right (style) |
|-----------------|---------------|
| "She uses XYZ Serum" | "Hero product is handled with reverent slow close-ups" |
| "She talks about ceramides" | "Dialogue features one scientific-sounding ingredient call-out" |
| "She's in a white bathroom" | "Setting is minimalist white-dominant, 3-4 anchor props" |

The template must be product-agnostic. The user's product replaces the reference's product.
