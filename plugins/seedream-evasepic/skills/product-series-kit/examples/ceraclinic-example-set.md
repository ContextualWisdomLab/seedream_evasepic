## 🎞️ Series Production Checklist

### Cross-episode consistency
- [x] Model: same face/hair across all 5 (only wardrobe changes in Ep3-4)
- [x] Product: identical description in every episode
- [x] Color palette: `#F8F4EF` + `#D4C5B2` anchor in every image prompt
- [x] Voice tone: measured expert-warm throughout
- [x] Lighting DNA: soft diffused overhead + warming toward Ep4

### Pre-production
1. Generate all 5 images in Seedream first:
   - Upload to Dreamina / fal.ai / Seedream API
   - Export at 1080×1920 (9:16) or 1080p equivalent
   - QA each image for: label legibility, skin texture, anatomy

2. Review images as a grid before proceeding — verify visual consistency

### Video generation
3. For each image, upload as `referenceImages` in Seedance 2.0:
```json
{
  "model": "seedance-2.0",
  "prompt": "<Episode N video prompt>",
  "aspectRatio": "9:16",
  "duration": 15,
  "resolution": "720p",
  "audioEnabled": true,
  "referenceImages": ["<filePath for Episode N image>"]
}
```

4. Poll until `status: "generated"`. Expect 30-90s per clip.

### Post-production
5. Stitch the 5 clips:
```bash
cd ~/your-project/outputs/
printf "file '%s'\n" ep1.mp4 ep2.mp4 ep3.mp4 ep4.mp4 ep5.mp4 > list.txt
ffmpeg -f concat -safe 0 -i list.txt -c copy ceraclinic-series.mp4
```

6. Add CTA text overlay in post (CapCut / Premiere) — do NOT ask Seedance to render text
